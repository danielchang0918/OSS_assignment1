[Key Learning]
1) 로컬에서 코드를 작성하고 Git이라고 하는 시스템을 활용하여 그것을 원격 저장소에 저장하고, 업데이트하는 법을 학습하였다.
2) Github에 저장되어있는 코드를 Vercel을 활용하여 실제 도메인처럼 배포하는 법을 학습하였다.
3) HTML 코드의 기본적인 구조와 작동 원리를 학습하였다. 

[Development Flow]
1) VS Code: 로컬에서 코드를 작성하고 수정 후 미리보기 기능을 이용하여 디버깅까지 완료.
2) Git: 주요 수정 사항이 있을 때마다, add + commit을 이용해 수정 기록 저장.
3) Github: push를 통해 수정된 코드를 원격 저장소에 저장 및 최신화
4) Vercel: 수정된 코드를 배포

[Code Modification]
1) AI가 임의로 생성한 자기소개글을 지우고 나만의 자기소개글로 재작성
2) 프로필 이미지 추가
3) 배경색 및 중간선 색 변경
4) 마지막 더 알아보기에 인스타그램 프로필 링크 추가

[Problem & Solution]
교수님께서 추가해주신 Repository가 Vercel에서 import되지 않았다. (에러 메시지: Installations and requests are disabled for this account.)
해결방법은 나만의 Repository를 새로 생성하여 해당 repo를 이용하여 배포를 진행했다. 

[Reflection]
Git이라는 시스템을 과거에도 몇번 이용하여 과제를 진행하고 수업을 들었음에도 불구하고, branch와 commit, push라는 개념이 항상 헷갈리고 어려웠었다. 
그런데 본 과제를 수행하며, 아주 간단한 코드를 수정하고, 수정 기록을 commit으로 저장하고, push해보는 실습을 해보니 어느정도 감이 잡힌 것 같다.
